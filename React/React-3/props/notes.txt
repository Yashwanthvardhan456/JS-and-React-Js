Props in React.js - Notes
Q. What are Props?
Props (Properties) are used to pass data from a parent component to a child component in React.

Props are read-only (immutable).
They help make components reusable.
Data flows in one direction: Parent ➝ Child.

Example
APP.JSX
import React from "react";
import "./App.css";
import Child from "./components/Child";

function App() {
  const name = "Binty";
  const age = 26;
  const con = "India";
  return (
    <>
      <div>
        <h1>Hello</h1>
        <Child name={name} age={age} country={con} />
      </div>
    </>
  );
}

export default App;

Child.JSX
import React from "react";

const Child = (prop) => {
  return (
    <div>
      <h1>Coming from child components</h1>
      <p>{prop.name}</p>
      <p>{prop.age}</p>
      <p>{prop.country}</p>
    </div>
  );
};

export default Child;
