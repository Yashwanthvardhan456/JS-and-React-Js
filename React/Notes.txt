Video 2: Understanding JSX and Displaying Dynamic Data in React
1)What is JSX
JSX stands for JavaScript XML
It allows you to write HTML inside JavaScript
React converts JSX into normal JS under the hood using something called Babel
JSX makes our code more Readable and easier to write.

2)How JavaScript can be written inside JSX?
import React from "react";

const App = () => {
  const display = () => {
    return "Welcome to React2";
  };
  const result = display();
  return (
    <div>
      {result}
    </div>
  );
};
export default App;


3)How data(Variables,functions,dynamic values) appears on Screen?
import React from "react";

const App = () => {
  const display = () => {
    return "Welcome to React2";
  };
  const result = display();
  const displayDate = new Date();
  return (
    <div>
      {result}
      <p>- {displayDate.toString()}</p>
    </div>
  );
};
export default App;

5) JSX Rules and best practices?
->Must return one parent Elements
->Use className instead of Class.
->Use camelCase for Attributes.
->All tags must be closed properly.
->Only expressions allowed (not Statements like if/for).
import React from "react";

const App = () => {
  const ClickFunc = () => {
    console.log("Clicked");
  };
  return (
    <div>
      <button onClick={ClickFunc}>Click</button>
    </div>
  );
};
export default App;
